# Original calibration evidence

This directory preserves the source calibration artifacts from the original workspace: camera/stereo YAML, spreadsheet, PDF reports, and rectification inspection images. The package does not load these files implicitly; `calibration/profiles/zed2i_37395692_custom.yaml` is the canonical computational profile.

The source translation is recorded in millimetres. The loader converts it once to metres. Source provenance does not establish housing/port geometry or independent underwater metric ground truth.
