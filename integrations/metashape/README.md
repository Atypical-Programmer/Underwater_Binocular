# Metashape integration

Use the exporter below to create an import package for every SFM project under
the selected dataset:

```powershell
conda run -n cv python scripts/export_sfm_projects_for_metashape.py
```

Each project receives `export/metashape/` containing:

- `metashape_cameras.xml`: camera transforms and a Metashape 1.7-compatible
  calibration, generated by the installed Metashape; small projects also get
  a headless round-trip check;
- `metashape_reference_ypr.csv` and `metashape_reference_opk.csv`: Reference
  pane CSV alternatives;
- `points3D.ply`: sparse COLMAP tie-point cloud;
- `image_list.txt`, `image_map.json`, and `README.md` for image paths and import
  order;
- `colmap_model/`: the exact source `cameras.txt`, `images.txt`, and
  `points3D.txt` files.

The XML is the convenient legacy-compatible import. The copied COLMAP model
retains the exact `FULL_OPENCV` parameters, including rational terms that the
Metashape 1.7 XML schema cannot store. For large camera sets, the exporter
records that Metashape 1.7.4's headless round-trip check was skipped; the XML
was still produced by Metashape itself. Coordinates are local and must not be
marked georeferenced without actual control points or treated as independently
verified underwater metric depth.
