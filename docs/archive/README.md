# Archived material

Historical reports and prior one-off scripts are retained for provenance and comparison. They are not the active package API, are not imported by production code, and may contain assumptions from the original workspace. Use the package, `configs/`, and `integrations/` for new runs.

The compact behavioral references under `validation/reference/` are the supported regression inputs. Large raw exports remain local under the existing ignored output locations and are not copied into this archive.
